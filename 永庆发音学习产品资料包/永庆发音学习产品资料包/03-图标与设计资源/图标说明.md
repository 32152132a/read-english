# 图标映射

通用图标建议统一使用 Lucide 或 Iconify 的 Lucide 集合，使用 SVG 方式引入：

| 场景 | 建议图标名 |
|---|---|
| 返回 | chevron-left |
| 搜索 | search |
| 播放 | volume-2 / play |
| 慢速 | clock-3 |
| 麦克风 | mic |
| 首页 | house |
| 我的 | user-round |
| 词库 | book-open |
| 评测 | headphones |
| AI纠音 | audio-waveform |
| 提示 | lightbulb |
| 完成 | circle-check |
| 锁定 | lock-keyhole |

定制图形：hero-face-wave.svg、mouth-open.svg。不要从UI PNG中抠图。Codex可以读取截图实现界面，但真实SVG资产比根据截图猜测更可靠。
