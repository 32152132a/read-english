# Codex 启动提示词

请基于 docs/product-design 中的产品文档、技术文档、UI截图和SVG资源，实现 UniApp X + Vue 3 + UTS 小程序。

要求：
1. 先阅读全部文档，输出页面路由、组件、数据模型和开发计划，再开始编码。
2. 建立设计变量与通用组件，不要按截图逐页复制样式。
3. UI截图是视觉目标；文字、状态和接口以文档为准。
4. 通用图标使用同一套Lucide SVG；定制图形使用资料包SVG。
5. 第一阶段先使用mock数据跑通：首页→单音标→对比→辨音→总览→进度保存。
6. 每完成一页，在390×844视口截图，与参考图对比并修正间距、字号和层级。
7. 不实现文档中标记为阶段2/3的真实服务，但保留路由、接口类型和“即将上线/完成基础后开启”状态。
8. 代码通过类型检查、构建和基础单元测试后再交付。
