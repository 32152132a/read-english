# 永庆发音学习产品资料包

本资料包用于交给 Codex 实现 UniApp X 小程序 MVP。

## 目录
- 01-UI界面：12张核心页面视觉参考
- 02-产品与技术文档：PRD、技术设计文档（DOCX/PDF）
- 03-图标与设计资源：定制SVG、图标映射、设计变量
- 04-开发清单：页面、接口、里程碑与Codex启动提示词

## 产品流程
基础学习：认识音标 → 音素与音节 → 看音标拼读 → 看单词拆读

进阶应用：专业词库 → 跟读评测 → AI纠音

## 使用原则
UI图是视觉目标，不是可直接切图的页面。开发时应使用组件、设计变量和SVG重建；中文文字、IPA、交互状态以文档为准。

## Codex 与图标
Codex 可以读取截图和设计说明实现前端界面，并通过浏览器截图继续做视觉对照；但对于图标，真实 SVG 资产应优先于从截图猜测。官方参考：https://learn.chatgpt.com/use-cases/frontend-designs

本资料包已经提供定制 SVG；其他通用图标按《图标说明.md》统一使用 Lucide，不需要再根据图片生成。
