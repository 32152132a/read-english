# 1. 产品定位

- 目标用户：希望系统学习美式发音的中文成人，优先覆盖程序员及互联网从业者。

- 核心痛点：认识单词但不会读；看到音标不会拼；遇到陌生词无法拆；缺少专业词汇练习。

- 核心差异：不以背词和翻译为主，而是提供“音标—音节—拼读—拆读—应用—纠音”的方法路径。

# 2. 产品主流程

基础学习：认识音标 → 音素与音节 → 看音标拼读 → 看单词拆读。

进阶应用：专业词库 → 跟读评测 → AI 纠音。

| **MVP 原则** 第一版只实现最小闭环；未实现功能保留入口并标记“即将上线”或“完成基础后开启”，但不让不可用入口抢占首页。 |

# 4. 首页规则

- “今日学习”卡片根据用户当前阶段动态显示标题、说明、按钮、目标路由和进度。

- 学习路径固定展示四个基础阶段；点击阶段可查看内容，系统仍推荐顺序学习。

- 后续阶段仅展示“专业词库 → 跟读评测 → AI纠音”，基础未完成时弱化显示。

- 第一版底部导航只保留“首页、我的”；学习页通过首页路径进入，避免重复。

# 5. 课程内容模型

| **阶段**   | **内容单元**                 | **练习方式**       |
|------------|------------------------------|--------------------|
| 认识音标   | 单音标、易混音对比、音标总览 | 听音、辨认、例词   |
| 音素与音节 | 音素、音节、重音、弱读       | 选择、标记、拆分   |
| 看音标拼读 | 元音定位、分段、重音、合读   | 逐步操作、答案揭晓 |
| 看单词拆读 | 字母组合、开闭音节、常见词尾 | 手动拆分、规则提示 |

# 6. 核心数据来源

- 单词：首批基础词与前端、Node.js、AI专业词由项目整理。

- 音标：CMUdict 美式音素转换为 IPA，并保存到自有数据库。

- 标准发音：有道英文词典发音，生成后保存至腾讯云 COS。

- 发音评测：腾讯云智聆口语评测，仅用于完整单词跟读阶段。

- 中文教学提示：规则模板与 AI 辅助生成，高频内容逐步校验。

# 7. 状态与交互规则

| **状态** | **展示**        | **行为**                   |
|----------|-----------------|----------------------------|
| 未开始   | 灰色节点/未开始 | 允许查看或按产品配置锁定   |
| 学习中   | 蓝色节点/进度   | 首页继续学习直达当前内容   |
| 已完成   | 绿色勾选        | 允许复习，不重复增加完成数 |
| 待复习   | 橙色提示        | 进入对应音标或错音练习     |
| 资源缺失 | 暂无标准发音    | 不进入正式词库，后台待补充 |

# 8. 第一版验收标准

- 用户能从首页进入当前学习内容并连续完成上一个/下一个。

- 音标标准音、慢速音和示例词可正常播放，失败时有重试提示。

- 学习进度可保存；重新打开后回到上次位置。

- 音标总览能一眼查看全部音标并单独播放。

- 基础四阶段入口和状态展示一致，未开发功能不产生死链。

- 页面适配常见微信小程序手机尺寸，核心按钮单手可触达。
